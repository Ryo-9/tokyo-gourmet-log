# TOKYO GOURMET LOG — UIデザイン方針（2026-11-19）

## 目指す印象

**スタイリッシュ、親しみやすい、直感的、読みやすい。** 「AIが生成したような見た目」を避け、毎日手に取る食の記録帳・街歩きのガイドとしてデザインする。

### 原則

1. **主役は店と体験**：架空の料理写真や過度な装飾を使わない。本人が保存した実際の写真があれば優先表示し、写真なしの場合は統一した線画と「写真なし」を明示する。
2. **画面ごとに一つの明確な目的**：ホームは「検索する」「地図で探す」「友達とつながる」。操作を詰め込み過ぎず、詳しい条件は必要な時だけ開く。
3. **色は絞る**：ライトは温かみのあるオフホワイト、文字は深いチャコール、アクセントは落ち着いたテラコッタ、訪問済みはセージ寄りの緑。ダークも同じ意味を保つ。装飾用の多数のグラデーションやピンク系カードの乱用を避ける。
4. **文字と余白に階層をつける**：見出し、本文、説明の3段階。説明文を最小サイズにしない。短い日本語ラベルを優先し、不要な英語コピーを増やさない。
5. **同じ意味の操作は同じ形**：下部ナビは5アイコン+日本語、選択状態を明示。料理ジャンルは同じ線幅のSVGアイコン。カードの角丸・線の太さ・フォーカス表示を揃える。
6. **指で操作できる大きさ**：重要な操作は原則44pt程度以上を確保。iPhoneのSafe Area、戻る操作、キーボード表示時、低視力・VoiceOverを考慮する。
7. **実装と説明が一致**：「近くで探す」は本人が操作した時のみ位置情報使用。SNSの一般公開フィードは未実装。訪問記録と写真を自動的に共有しない。
8. **体験で評価する**：画面を長文で説明するのではなく、初回ユーザーが3秒で「何ができるか」を理解できるか、検索・保存・記録まで操作できるかを検証。
