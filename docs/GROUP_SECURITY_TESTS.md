## 現在の制限

- グループへの招待は双方がメール認証済みで、ユーザーコードを友人同士で交換する必要がある。プロフィール検索・友達検索はまだ実装していない。
- 招待されたユーザーが承認するまではメンバーには入れない。
- グループ作成者は現状、メンバーを強制削除できない。本人の退会と、作成者によるグループ全体削除は可能。モデレーション・ブロックを追加してから強制退出を検討。
- 個人の `tgl_saved_places` / `tgl_visits` / `tgl_posts` を、グループ参加だけを理由に読めるようにはしていない。
- 今回はSQL権限模擬であり、**実際のiPhone端末を2台使用した招待・共同投票テストは未完了**。UIは未ログインブラウザで表示確認済み。
- 新たに作ったグループ用5テーブルには、セキュリティアドバイザーの新しい警告なし。旧音楽アプリ由来の`public.add_owner_as_song_member()`関数の警告などは残るため別途対応が必要。
